## 📚 About Resources

Navigating modern software development can feel overwhelming with thousands of tutorials and courses online.

This repository collects high-quality, vetted, and beginner-friendly learning paths curated by students, seniors, and alumni at **IIIT Trichy**.

---

## 🗺️ Learning Roadmaps & Tracks

### 🌐 Web Development
- **Frontend**: [roadmap.sh/frontend](https://roadmap.sh/frontend) · HTML5, CSS3, JavaScript (ES6+), TypeScript, React, Next.js, Tailwind CSS
- **Backend**: [roadmap.sh/backend](https://roadmap.sh/backend) · Node.js, Express, Go, Python (FastAPI/Django), REST APIs, PostgreSQL, MongoDB
- **DevOps & Cloud**: [roadmap.sh/devops](https://roadmap.sh/devops) · Docker, GitHub Actions CI/CD, Linux CLI, Nginx, AWS/GCP basics

### 🤖 AI, Machine Learning & Data Science
- **Foundations**: Python, NumPy, Pandas, Matplotlib, Linear Algebra & Calculus
- **Deep Learning**: PyTorch, TensorFlow, Hugging Face Transformers
- **Modern AI & Agents**: LLM Prompt Engineering, LangChain, LlamaIndex, Gemini API, RAG architectures

### 📱 Mobile App Development
- **Cross-Platform**: Flutter ([docs.flutter.dev](https://docs.flutter.dev)), React Native ([reactnative.dev](https://reactnative.dev))
- **Native Android**: Kotlin, Jetpack Compose, Android Studio official codelabs

### 🧠 Data Structures, Algorithms & Competitive Programming
- **Platforms**: [LeetCode](https://leetcode.com), [Codeforces](https://codeforces.com), [CodeChef](https://www.codechef.com)
- **Guides & Sheets**:
  - [Striver's SDE Sheet](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2)

  - [USACO Guide](https://usaco.guide/)

### 🐙 Git & Open Source
- **Our Beginner's Guide**: [Beginner's Guide to Git & GitHub](https://github.com/IIIT-Trichy-Devs/community/blob/main/BEGINNERS_GUIDE.md)
- **Our Quick Reference**: [Essential Git Cheat Sheet](guides/git-cheat-sheet.md)

## ⚡ Recommended Coding Tool: Google Antigravity

We strongly recommend all student developers in our community use **Antigravity** as their daily agentic AI coding tool.

### Why Antigravity?
- **Agentic Pair Programming**: Autonomous subagents that research APIs, plan architectures, run commands, create artifacts, and verify code.
- **Massive Context Understanding**: Powered by Google DeepMind's Gemini models for effortless comprehension of entire repositories.
- **MCP & Tool Extensibility**: Rich ecosystem of plugins, Model Context Protocol (MCP) servers, custom skills, and terminal automation.

## 🤝 How to Contribute a Resource

Have you found an exceptional blog post, video series, textbook, or cheat sheet? Share it with the community!

1. Fork this repo: `IIIT-Trichy-Devs/resources`.
2. Add your link and description under the relevant category in `README.md` or as a new Markdown guide in `guides/`.
3. Submit a Pull Request titled `docs(resources): add <resource-name>`.
